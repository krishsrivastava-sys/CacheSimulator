# CUSTOM CacheSimulator

This project simulates how the cache hits, misses and evictions, using a valgrind trace, counting and printing the result.


## What is valgrind?
> Valgrind is an open source tool that is used to trace memory leaks, understand and modify a compiled binary in *Runtime*.

## Valgrind Trace files
> We are going to use trace files generated by valgrind and provided in the 15-213 CSAPP Labs present online.

### What are valgrind trace files?
using the tool `lackey` these trace files are custom generated using the command:

`linux> valgrind --log-fd=1 --tool=lackey -v --trace-mem=yes`

They look something like this: </br>
```
I <Address>, 8
M <Address>, 6
L <Address>, 2
S <Address>, 9
```
